# Content log

Use one row per draft. Keep source notes in private working files. Copy this template only when a batch or tracking task needs it.

| ID | Channel | Main point | Source | Closest prior item and difference | Status | Proposed date | Published date and URL | Dated results | Feedback |
|---|---|---|---|---|---|---|---|---|---|

Allowed status values: draft, approved, scheduled, published. A proposed date is not proof of scheduling. Record missing analytics as unavailable. A substantive revision to approved or published content is a new draft revision.
